# 「輪をドラッグ」の消去条件と配置

比較元: `013a386d4abb5f8a15bffd62a616a0a83a01501e`。

- 任意のキャンバスドラッグや矢印キーを案内消去の根拠にする処理を削除。
- Morse 球面は実際の grip 解の深さ・横変位が変わったとき、Morse トーラスは実際の深さが変わったときだけ消去通知する。
- 輪郭側も操作点ドラッグによる深さ・横変位の変化があったときだけ通知する。
- バーの input は従来どおり消去する。空白、回転、ズームを消去の理由にしない。
- 回転モードでは一時的に隠し、変形に戻ると未消去なら再表示する。
- 同じページの球面・トーラス間で初回記録を共有する既存 sessionStorage の仕様は維持。操作前の同タブ再読込では表示、実操作後の再読込では非表示。独立した新規タブでは再表示する。過去の版で既に消去済みとなった記録は消していない。

案内をキャンバスの親のクリッピングから外し、元の操作点を基準にビューポートと固定操作部の上端へ収める。スクロール・リサイズ・操作部の寸法変更時も位置を更新する。変形用キャンバス自体が見えない場合は別の図に案内を重ねず、スクロールして変形用の図が見えたとき表示する。375×667 の Morse 初期画面はこれに該当する。390×844 では初期から固定操作部の上に表示される。文章・ボタンの追加なし。

## 確認

`ui.cjs/json`: Chromium/Playwright、PC 1440×1000・タッチ模擬 390×844、両ページ×球面/トーラスの 8 ケース。初回、回転ドラッグと矢印、空白ドラッグ、操作前の同タブ再読込、実際の操作点ドラッグによる消去、操作後の再読込、独立した新規タブ、バーの実タップ/クリックを確認。エラーなし。

`layout.cjs/json`: 375×667・390×844・430×932・844×390 で初期と最下部を確認。配置の数値判定と PNG を保存。Morse 390 初期、375 スクロール後の画像を目視確認。

`math-unchanged.json`: 両ページの埋め込み Worker は比較元と同一。変形核・臨界点・輪郭の計算処理には変更なし。今回は案内の通知と配置のみ。

実機 Safari/Android は未確認。公開 github.io への通信は環境の CONNECT 403 制限があるため、画面確認はローカル配信、配備確認は正確な remote SHA と Pages workflow の成功を用いる。

再実行はリポジトリ直下をポート 8003 で配信し、Node + Playwright + `/usr/bin/chromium` で各 cjs を実行する。
