# 初期表示の上下左右へトーラスの操作点を移動

基準コミット: `e783b83fd6025932b717777fc061272d97bdedaf`。対象は両 HTML のトーラスだけ。本文・UI のボタン・初期姿勢・倍率・変形強度・範囲・球面と他曲面は変更していない。

## 配置

既存の局所変形 F をトーラス軸回りの回転 R により `R F R⁻¹` に移す。操作点の sourceAnchor も同じ角度だけ移す。曲面全体の初期姿勢を回したり、変形中の見え方に合わせて操作領域を動かしたりはしない。

- Morse 側: 初期の高さ方向の方位角が 24°。右・上・左・下の操作点をそれぞれ −66°・24°・114°・204° に置き、変形する側の画面で方向と一致させた。上のマーカーは真上、右のマーカーは真右に位置する。元の曲面を表示する左側は別の視点なので、その画面上の上下左右とは異なる。
- 輪郭側: 初期投影の右端方向 0° と上端方向約 91.58° に対して、4 操作点が直角間隔を保つ最小二乗の共通補正角約 +0.791° を採用。初期投影はすでにほぼ上下左右なので小さな補正となる。左側の斜めから見た立体像の外接矩形の端に合わせた配置ではない。斜めの立体像とスクリーン上で同時に厳密な上下左右にすることはできないため、射影先の対応を優先した。

Morse の初期姿勢では右・左の変位は高さ方向と直交するため、高さの特異点の増減は上・下で観察する。これは配置を方向と一致させたことの帰結であり、回転で操作点を自動追従させることはしない。

## 特異点と見た目

元の右側操作点では対生成の深さは約 −.5146858（上限 −.55）。新しい上の操作点では約 **−.09465749**。前後 .005 で [極小, 鞍点, 極大] は [1,2,1] と [1,3,2]、双方の交代和は 0。上下を厳密に合わせた対称配置なので、境目では中央の点と左右に生まれる点が合流する対称な退化になる（一般位置の単純な birth–death と同一とは主張しない）。境目は valid=false で未確定となる。境目の未分類候補は近接した数値候補であり、その数を臨界点個数として表示しない。

−.20 では山 2 つと峠を、−.35 では上のくぼみを視認できる。`morse-0.png`・`morse--0.2.png`・`morse--0.35.png` を参照。角度 0°・10°・18°・24°、深さ −.2・−.3・−.4 の試行を `angle-trials.json` に保存。

## 検証

- `invariance.cjs/json`: 両ページそれぞれ 16,000 点。旧写像との回転共役の誤差、支持外の変位、他操作点の変位、局所変形の合成誤差を確認。全て 2e-15 程度以内。旧写像の可逆性・穴の保存・独立性は回転共役でそのまま維持される。Jacobian 行列式の解析的下界 .05283 も変わらない。
- `curvature.cjs/json`: −.2・−.4・−.55・+.55 の各 60×60 点で回転対応する点の主曲率を比較。最大差 <5e-7。剛体回転の共役なので、縁の滑らかさ・曲率は理論上同一。今回の数値差は有限差分の丸め誤差。
- `numerics.cjs/json`: 8 種の操作状態、32²・52²・76² 種点の臨界点・指数の一致、Euler 整合性、周期接合、正則性、両ページの回転対応、軌道、逆像を確認。輪郭は 5 種の深さを level 4/5/6 で検査。
- `fold.cjs/json`: 退化の境目を勾配・Hessian の行列式から探索し、境目の未確定と前後の確定を確認。
- `cusps.cjs/json`: 傾けた射影でカスプの生成と成分次数を 3 解像度で確認。
- `fixed-view.cjs/json`: 表示中心・倍率・他の操作点の位置が変形で動かず、手動ズームが保持されることを確認。
- `ui.cjs/json`: PC 1440×1000 / タッチ模擬 390×844 で両ページのバー、上の操作点のドラッグ、回転、リセット、曲面切替・再選択、全角入力・正解表示・成分選択を確認。
- `marker-directions.cjs/json`: スマホ模擬でマーカーが画面の上下左右と一致することを座標で確認。実際のバータップにより深さ −.231 で [1,3,2] となることを確認し、`mobile-shallow.png` を目視確認。
- `regression.cjs/json`: 球面の主要計算モジュールは基準と同一、他の 6 曲面の写像の差は 0。

Chromium/Playwright によるローカル配信での検査。実機 Safari/Android は未確認。数値検証は選んだ状態と解像度での確認であり、全てのパラメータで完全性を証明するものではない。公開 github.io は環境の CONNECT 403 制限があるため、配備は正確な remote SHA と Pages workflow の成功で確認し、公開 URL の直接取得と区別する。

再現はリポジトリをポート 8005 で配信し、Node/Playwright と `/usr/bin/chromium` で cjs を実行する。
